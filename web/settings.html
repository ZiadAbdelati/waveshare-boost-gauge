Gauge range

Defaults −15 / 10 / 8 PSI and 236.25°. Zero position controls the notch; the optional midpoint label disappears if it would overlap overboost.

Display

Nudges the whole gauge by a pixel or two every 90 s so fixed elements — tick rings, labels, box outlines — don’t age into the panel. Shifts wait for a steady reading, so they land where nothing is moving.

Keeps the ground a fixed dark colour instead of sweeping it through the zone colours. Removes the only full-screen repaint in any face (worst render cycle 46 ms → 17 ms) and lights far fewer emitters.
