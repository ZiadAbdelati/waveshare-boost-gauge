Gauge range

Defaults −15 / 10 / 8 PSI and 236.25°. Zero position controls the notch; the optional midpoint label disappears if it would overlap overboost.

MAP atmosphere calibration

The GM 12223861 curve is defined at 5.00 V and the sensor is ratiometric, so the real supply is normalized out before the transfer function is applied. Measure it at the sensor connector. Saves on its own; changing it recomputes an existing offset against the same stored atmospheric reference.

Confirm all three before calibrating:

  • The engine is off.
  • The gauge stays powered for the whole two-second measurement.
  • The MAP port and the BMP280 are both open to the same atmosphere — no vacuum line still connected to the manifold.

Aligns the MAP sensor to the BMP280 at a known pressure. The measurement takes about two seconds and replaces any previous offset — offsets never compound. Nothing is written unless every check passes.

Display

Off drives the gauge from the real MAP and ambient sensors and hides the DEMO marker. On replays the synthetic idle-to-boost sweep and shows DEMO on every face — handy with no engine running.

Locks screen updates to the panel’s refresh so partial redraws don’t land mid-scan. Steadier, but it can drop the odd frame — toggle it and see which you prefer.

Stages the whole changed area off-screen first, then sends it to the panel in one burst instead of dribbling it out while drawing. Aims to remove the rest of the needle tearing that tear sync alone doesn’t catch. Costs a few frames per second and roughly doubles the worst-case frame time, so judge it by eye — if the needle looks the same, leave it off.

Quarter turns only — these map onto the panel’s own scan order and cost nothing per frame. Arbitrary angles would need the whole frame resampled on every redraw, which this display cannot do and hold 60 FPS. Takes effect after a restart.

Nudges the whole gauge by a pixel or two so fixed elements — tick rings, labels, box outlines — don’t age into the panel. Each nudge costs one full-screen repaint (~45 ms), so it waits up to 30 s past the interval for a steady reading and lands where nothing is moving. More often is gentler on the panel; less often is fewer repaints.
